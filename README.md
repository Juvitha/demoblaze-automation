# DemoBlaze Test Automation

Playwright + TypeScript framework using the Page Object Model.

## Setup
1. `npm install`
2. `npx playwright install`
3. Copy `.env.example` to `.env`

## Run
- `npx playwright test`
- `npm run allure:generate` then `npm run allure:open`

## Structure
locators, pages, fixtures, utils, testdata, tests
